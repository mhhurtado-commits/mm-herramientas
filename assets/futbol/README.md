# Recursos visuales de fútbol

Este directorio contiene los recursos locales utilizados por `visual-suite` para
renderizar placas de fútbol sin depender de imágenes externas durante la exportación.

## Estructura

- `equipos/`: escudos de clubes en PNG.
- `competencias/`: logos y trofeos de torneos.
- `catalogo.json`: claves, nombres y procedencia de cada recurso.

## Fuentes

Los recursos se descargan desde Wikimedia Commons cuando existe un archivo
identificable. Los escudos son marcas de sus respectivos clubes y se utilizan
como referencia editorial dentro de las placas de Media Mendoza.

Como referencia alternativa de temporada se utiliza FootyLogos, que mantiene
un catálogo actualizado de los 30 equipos de la Liga Profesional Argentina 2026:
https://www.footylogos.com/es/competition/liga-profesional
