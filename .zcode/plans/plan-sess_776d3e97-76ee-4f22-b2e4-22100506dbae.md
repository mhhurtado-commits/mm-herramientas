# Plan: Mini-web interactiva y autónoma (Publicación Web Media Mendoza)

## Decisiones (confirmadas con el usuario)
- **Formato:** HTML autónomo descargable (un `.html` con CSS + datos inline y librerías por CDN; se puede abrir directo o publicar en Cloudflare Pages). Sin build step.
- **Composición:** Web narrativa combinada — una sola "historia" con hero + gráfico + mapa + cronología + infografía + footer de marca, con navegación y scroll animado.

## Objetivo
Reutilizar los datos que YA se generan/cargan en Visual Suite para producir una publicación web interactiva y profesional (más allá de las placas PNG estáticas), sin tocar el worker ni el modelo de Gemini, y respetando la identidad corporativa (`--v:#a6ce39`).

## Enfoque
Un nuevo botón **"🌐 Publicación Web"** en la barra global recoge el estado vivo de los 4 módulos, ensambla un objeto `DATA` y genera un HTML autocontenido que se previsualiza en un modal (`<iframe srcdoc>`) y se puede descargar.

### 1. Recolección de datos (sin cambios en el worker)
Se leen los estados ya existentes y globalmente accesibles (scripts clásicos comparten scope):
- `titulo`: `#chartTitle` / `#infoTitle`.
- `chart`: `chartInstance.data` (`labels`, `datasets`) + `#chartTitle` + `#chartType` (puede ser `null`).
- `mapa`: `markerList` → `[{lat,lng,title,desc}]` (puede ser `null`).
- `timeline`: `timelineEvents` → `[{date,title,desc}]` (puede ser `null`).
- `infografia`: `#infoTitle`, `#infoContent`.split('\n'), `templateActual`, `#infoColor1/2`.
- `logo`: convertir `logoState.img` a **base64 data URI** (`canvas.toDataURL`) para que el archivo sea 100% autónomo (sin ruta relativa `../assets/logo.png`).
- `DATA = { titulo, chart, mapa, timeline, infografia, logo, generado }`.

### 2. Estructura del HTML generado (narración combinada)
1. **Header sticky** con marca + nav de anclas (Gráfico · Mapa · Cronología · Datos), smooth-scroll.
2. **Hero:** kicker `MEDIA MENDOZA`, H1 con `titulo`, dateline.
3. **Sección Gráfico** (si `chart`): `<canvas>` + init de Chart.js 4.4.7 desde `DATA.chart` (tooltip/leyenda interactivos).
4. **Sección Mapa** (si `mapa`): `<div id="map">` + init de Leaflet 1.9.4 con markers/popups y `fitBounds`.
5. **Sección Cronología** (si `timeline`): timeline vertical construida desde eventos, con reveal por `IntersectionObserver`.
6. **Sección Infografía** (si `infografia`): grid responsive de tarjetas de datos, estilo según `template` (simple/comparativa/listado/destacado).
7. **Footer:** banda oscura `#16201b` con logo (base64) + "MEDIA MENDOZA · mmherramientas.media".
- Render condicional: cada sección solo aparece si hay datos (degrada sin errores si falta un módulo).

### 3. Sistema de diseño (tono profesional)
- Paleta de marca inline: `--v:#a6ce39`, `--v-dark`, `--ink:#16201b`, `--paper:#ffffff`/`#f3f5f2`, oro `#c9a227`. **No se cambia `--v`.**
- Tipografía: Inter (texto) + DM Serif Display (titulares), vía Google Fonts `<link>`.
- Responsive mobile-first, scroll-reveal, nav sticky, buen ritmo de espaciado.
- **Logo legible:** en la web generada se coloca sobre superficie oscura (footer / header) para que sus partes blancas no se pierdan (resuelve la preocupación de fondos claros).

### 4. Archivos a crear / modificar
- **CREAR `visual-suite/publicacion.js`** con:
  - `generarPublicacionWeb()` — recolecta `DATA`, construye el string HTML (template literal con CSS + `window.MM_DATA` + scripts de init de Chart.js/Leaflet desde CDN) y lo muestra en `<iframe srcdoc>` dentro del modal.
  - `descargarPublicacionWeb()` — `Blob` → descarga `publicacion-media-mendoza.html`.
  - `getLogoDataUri()` — `logoState.img` → base64.
- **MODIFICAR `visual-suite/index.html`**:
  - Botón **"🌐 Publicación Web"** en la barra global (junto a "Exportar PNG", ~línea 503) con `onclick="generarPublicacionWeb()"`.
  - Modal de previsualización web (~tras línea 772): `<iframe id="webPreviewFrame">` + botón "⬇ Descargar HTML".
  - `<script src="publicacion.js"></script>` (~línea 781, tras `infographics.js`).
- **NO se modifica** `worker/worker.js`, `app.js` (el botón usa `onclick` global), `charts/maps/timeline/infographics.js`, ni `--v`.

### 5. Autonomía del archivo
- Logo embebido como base64 (sin assets externos).
- Librerías (Chart.js, Leaflet) por CDN, igual que hoy en la suite.
- Datos inline en `window.MM_DATA`. Sin `fetch` a nada interno.

## Fuera de alcance
- No se reemplazan las placas PNG (la mini-web las complementa).
- No se toca el modelo de Gemini ni los prompts del worker.
- No se introduce build step (Vite/React).
