# Plan: Extensión "Publicación Rica" para Visual Suite

## Objetivo
Extender la miniweb actual (publicacion.js) para incluir **recursos gráficos descargables individualmente** (iconos SVG + ilustraciones PNG) que se generan a partir de los datos ya cargados en los 4 módulos, con opción de ajuste manual. La nueva "Publicación Rica" convive con la miniweb actual.

## Decisiones confirmadas con el usuario
- **Recursos**: Iconos vectoriales (SVG) por categoría + ilustraciones raster (PNG) para notas
- **Descarga**: Elemento a elemento (no ZIP)
- **Relación con actual**: Extensión (ambas disponibles)
- **Personalización**: Híbrida — auto-generación desde datos actuales + edición manual opcional
- **Modelos**: No tocar Gemini; si se requieren imágenes generadas, usar el endpoint `/visual/generar` existente (FLUX/SDXL) u otro agente opcional

---

## Arquitectura propuesta

### 1. Generador de recursos (`publicacion.js` → nuevo módulo `recursos.js`)
Crear `visual-suite/recursos.js` que exponga:
- `generarIconosSVG(datos)` → array de `{id, categoria, svgString, nombreArchivo}`
- `generarIlustracionesPNG(datos)` → array de `{id, descripcion, blob, nombreArchivo}` (usa canvas + toBlob)
- `descargarRecurso(recurso, formato)` → descarga individual via `URL.createObjectURL`

**Fuentes de datos (auto-generación):**
- Charts → iconos de tipo de gráfico + mini-charts embebidos
- Mapa → iconos de ubicaciones + mini-mapas estáticos
- Timeline → iconos de eventos cronológicos
- Infografía → iconos de datos clave + tarjetas ilustradas

**Entrada manual (híbrida):**
- Panel lateral en la miniweb para editar prompt/parámetros antes de generar
- Botón "Regenerar recurso" por elemento

### 2. Integración en la miniweb existente
En `publicacion.js`, modificar `construirHTML(D)` para añadir una **sección "Recursos para tu nota"** al final (antes del footer):
- Galería en grid responsive con tarjetas por recurso
- Cada tarjeta: preview + botón "Descargar SVG/PNG" + badge de categoría
- Solo se muestra si hay recursos generados

### 3. UI en Visual Suite (`index.html`)
- Nuevo botón **"🎨 Publicación Rica"** junto a "🌐 Publicación Web"
- Modal de previsualización extendido con pestaña "Recursos"
- Opción "Generar recursos" en el flujo de extracción de URL

### 4. Pipeline de generación (sin tocar Gemini)
```
Datos módulos actuales → recursos.js (plantillas SVG/Canvas) → Miniweb HTML con galería → Descarga individual
```

Para ilustraciones que requieran IA:
- Reutilizar `handleVisualGenerar` (endpoint `/visual/generar` → FLUX/SDXL) con prompts estructurados desde `recursos.js`
- Fallback: plantillas Canvas locales si falla la IA

### 5. Plantillas base (assets reutilizables)
- `/assets/icons/` — SVGs base por categoría (economía, deportes, política, clima, etc.)
- `/assets/ilustraciones/` — Plantillas Canvas para ilustraciones tipográficas/diagramáticas
- Se pueden ampliar luego sin cambios de código

## Fuera de alcance
- No se reemplaza la miniweb actual
- No se cambia el modelo Gemini ni `callGemini`
- No se introduce build step / bundler
- No se crea backend de almacenamiento de recursos (todo client-side)
