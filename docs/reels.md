# Reels editoriales

`/reels/` es una herramienta independiente para convertir una noticia en una secuencia vertical 9:16.

- Acepta una URL directa o el handoff de `/placas-v2`.
- Usa el paquete editorial común, pero tiene modelo y renderer propios.
- Mantiene la imagen horizontal completa con fondo adaptativo y permite arrastrar el foco sobre el canvas.
- Genera portada, desarrollo, dato clave cuando existe y cierre con CTA.
- Exporta cada escena como PNG. El audio se incorpora al publicar en Instagram.

El worker continúa desplegándose manualmente en Cloudflare, igual que el resto de la suite.
